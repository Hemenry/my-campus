# 阿里云 ECS + 阿里云域名 · 上线前配置清单

面向：阿里云 ECS（含轻量应用服务器）部署 GeekCampus，域名走 HTTPS。
前置：域名已完成 ICP 备案，且备案接入商是阿里云（否则 80/443 会被拦截）。

---

## 1. ECS 实例侧

### 1.1 规格与系统

| 项 | 建议值 | 说明 |
|---|---|---|
| 实例规格 | 2 vCPU / 4 GiB 起 | MySQL 8 空载约 400MB，2C2G 能跑但余量小，脚本已按 2G 调参 |
| 镜像 | Ubuntu 24.04 LTS 64 位 | 部署脚本按它写的，CentOS 需改包名 |
| 系统盘 | 40 GiB 起 | 含系统 + 日志 + 上传文件 |
| 公网 IP | 建议绑 EIP | 固定公网 IP 在实例释放后会变，EIP 可保留并随时换绑 |

> 阿里云 Ubuntu 公共镜像的默认登录用户是 `root`，与 AWS 的 `ubuntu` 不同。
> 创建实例时如果选了"密钥对"，后续就用对应私钥登录。

### 1.2 安全组（ECS）

位置：ECS 控制台 → 实例 → 安全组 → 配置规则 → **入方向** → 手动添加。

| 协议类型 | 端口范围 | 授权对象 | 优先级 | 用途 |
|---|---|---|---|---|
| TCP | 22/22 | **你自己的出口 IP/32** | 1 | SSH，禁止对全网开放 |
| TCP | 80/80 | 0.0.0.0/0 | 1 | HTTP，也是 certbot 验证与 HTTPS 跳转入口 |
| TCP | 443/443 | 0.0.0.0/0 | 1 | HTTPS |
| ICMP | -1/-1 | 0.0.0.0/0 | 1 | 可选，方便 ping 排查 |

要点：

- 优先级数字越小越优先（1–100），冲突规则以数字小的为准。
- **不要**放行 3306 和 5001，MySQL 与 Gunicorn 只监听 127.0.0.1，对外开也连不上。
- 出方向保持默认全放行即可。

### 1.3 轻量应用服务器的差别

如果你用的是**轻量应用服务器**而不是 ECS，端口不在"安全组"里配：

位置：轻量应用服务器控制台 → 服务器 → 安全 → **防火墙** → 添加规则。
规则内容同上，但它没有优先级字段，且 22 端口建议直接关掉或限制来源 IP。

## 2. 域名侧（云解析 DNS）

位置：阿里云域名控制台 → 域名列表 → 解析 → 添加记录。

| 记录类型 | 主机记录 | 记录值 | TTL |
|---|---|---|---|
| A | `@` | ECS 公网 IP | 600 秒 |
| A | `www` | ECS 公网 IP | 600 秒 |

要点：

- 记录值填**公网 IP**，不是内网 IP。ECS 里 `ip addr` 只显示内网 IP，公网 IP 在控制台看，或服务器上执行 `curl ifconfig.me`。
- TTL 默认 10 分钟，调成 600 秒方便改动后快速生效。
- 不要开泛解析（`*`），容易被恶意指向。
- 域名可以在别的注册商买，不影响解析到阿里云 ECS。

### 解析生效验证

```bash
nslookup 你的域名 223.5.5.5        # 阿里 DNS
nslookup www.你的域名 8.8.8.8      # 交叉验证
curl -I http://你的域名            # 返回 200 或 301 即通
```

刚改完解析没生效是正常现象，等 10 分钟；超过 1 小时不生效去查 DNS 配置。

## 3. 备案（前置条件）

- 国内节点服务器绑域名走 80/443，**必须先备案**，否则阿里云直接拦截并返回备案提示页。
- 备案在阿里云 ICP 备案系统提交，需要该 ECS 生成的**备案服务码**（每实例最多 5 个）。
- 审核通常 3–20 个工作日，备案通过后才建议绑域名对外。

---

## 4. HTTPS 证书

推荐 **certbot（Let's Encrypt）**：免费、90 天有效期、可自动续期，部署脚本已按它设计。

```bash
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名 -d www.你的域名
```

签发后有两件事必做：

```bash
sudo certbot renew --dry-run                      # 验证自动续期链路通不通
sudo systemctl list-timers | grep certbot         # 确认续期定时器在跑
```

**HTTP-01 验证失败时**（国内偶发，表现为 `Timeout during connect`）：改用 DNS-01 验证。
阿里云 DNS 可用 `certbot-dns-aliyun` 插件，或在证书到期前手动改用阿里云免费证书
（控制台每年可领 20 张 DV 证书，有效期 3 个月，需手动下载并配置到 nginx）。

## 5. 阿里云环境特有的坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面打不开，SSH 能连 | 安全组/防火墙没放行 80/443 | 检查入方向规则，ECS 与轻量是两套位置 |
| 服务器内 `ip addr` 看不到公网 IP | ECS 是内网网卡 + NAT 映射 | 公网 IP 看控制台，或 `curl ifconfig.me` |
| 访问域名跳"未备案"提示页 | 域名没备案或没接入阿里云备案 | 先备案，再用 80/443 |
| 80 端口被占用导致 nginx 起不来 | 轻量服务器的预装镜像自带 Apache | `ss -lntp \| grep :80` 找出进程，停掉或卸载 |
| apt 装包慢 | 镜像源非阿里云 | 公共镜像默认已是阿里云源，无需改 |
| certbot 验证超时 | 80 端口未放行 / 被劫持 | 改用 DNS-01 验证 |

## 6. 配置完成后

把下面几项交给部署流程：

1. 服务器**公网 IP**
2. **域名**（@ 与 www 已解析到该 IP）
3. SSH **端口**与**登录用户名**
4. 用于免密登录的**公钥**（已生成，见部署流程）

之后执行：

```bash
bash deploy/upload.sh --host <IP> --user root --domain <域名>
# 服务器上
sudo bash /srv/geekcampus/deploy/bootstrap.sh
sudo certbot --nginx -d <域名> -d www.<域名>
```
